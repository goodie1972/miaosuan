⑩ 说明 / 帮助

      

        bar1 语义 —— 为什么策略不会重绘？
        
导出文件的 generate_signal 只用已收盘 K 线（candles[:-1]），
        最后一根正在形成的 K 线不参与任何计算，因此不存在未来函数（repaint）。
        AF001 lint 规则会静态拦截任何读取未收盘 K 线的写法。

      

      

        DSR 是什么？
        
DSR = Deflated Sharpe Ratio（去膨胀夏普）。搜索过程试了几千个公式，最优结果天然带“选择偏差”；
        DSR 把试验次数折算进去，看扣掉运气后还剩多少。门禁阈值 DSR ≥ 0.5，低于即 BLOCKED。

      

      

        BLOCKED 意味着什么？
        
未通过实盘门禁：导出文件会被强制打上 RESEARCH_ONLY 警示块、
        DEPLOYABLE=False，仅供研究 / 模拟，禁止上实盘。需要重新过门禁并重新导出才会去掉警示。

      

      

        词表冻结锁（VOCAB_VERSION）的作用
        
token 只在同一词表下有意义。导出文件内嵌 VOCAB_VERSION，
        AF007 规则会与当前内核词表逐位比对；一旦特征/算子顺序变动，旧策略立刻被检出，
        避免“拿旧 token 喂新内核”的静默错算。
