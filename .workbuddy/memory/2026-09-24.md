### 关键教训（可复用）
- **多 Python 环境机器上，launcher 必须优先探测项目 .venv**，否则系统 Python 找不到 editable 安装的包。
- 启动器健康检查要用项目**真实存在**的端点（妙算用 `/api/meta`），照抄别的项目模板前先 grep 端点是否存在。
- PowerShell 重定向输出是 UTF-16，读取前需用 Python `decode('utf-16')`；stdout 经常捕获为空，统一改为「脚本写文件 + Read 文件」模式。
