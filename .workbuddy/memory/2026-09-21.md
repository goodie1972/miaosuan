  `https://freeserv.dukascopy.com/2.0/rest/ps/public/candles`，**无需登录**；

  （`describe()` 输出 `anonymous (public history)`）。

  过期后要么新建、要么转 live。

  再申请「加长有效期模拟账户 / Extended validity DEMO」——**无限有效期，
  但需至少每 14 天使用一次**。
- 本沙箱 `freeserv.dukascopy.com` 不可达（TCP 超时 / 代理 502），无法本地实证取数；
  属沙箱网络限制，与 TradingView / Binance 同类。

### 发现的缺陷（待修，已向用户提出）
- `DukascopyFetcher.is_available()` **恒为 True**，不做任何可达性探测；
  且 `_fetch_raw` 里 `except DataError: break` 会把 HTTP 失败**静默吞掉**，
  最终只报「Dukascopy 无数据」，掩盖真实的网络/接口错误，误导排查。
- 建议修法：与 `BinanceFetcher` 一致——加 TCP 可达性探测（AF_INET 单地址 + 结果缓存），
  并让 HTTP 错误向上抛出而非静默 break。
- **已修**（见下条日志）：`is_available()` 改带缓存的 IPv4 TCP 探测（`probe_timeout=3`），
  `_fetch_raw` 的 `except DataError: break` 改为向上抛 `DataError("Dukascopy 拉取中断（窗口 …）")`。

### ⚠️ 关键环境教训（踩了三次）
**在本环境跑 pytest 必须加 `--basetemp` 且加 `-p no:cacheprovider`**：
```
.venv\Scripts\python.exe -m pytest tests -q --basetemp <项目内目录> -p no:cacheprovider
```
否则收尾清理 `%TEMP%\pytest-of-*` 或写 `.pytest_cache` 会触发沙箱 SAFE_DELETE_BULK_REJECTED，
导致 **EXIT=1 的假失败**（进度条里没有任何 F/E，极难察觉）。工程师为此连续三次被拦截、误判为有回归。
另外：**删除文件超过 50 个会被沙箱 bulk-reject**（`.pytest_h1/` 186 个文件被拒），需用户手动清理。
