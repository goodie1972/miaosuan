- **性能坑（重要）**：`is_available()` 不可用真 import——akshare / tvDatafeed 是重包，首次 import 数秒 → 改用 `importlib.util.find_spec`。另外 `socket.create_connection(host,port)` 会依次试 IPv6/IPv4 两个地址族，主机不可达时耗时翻倍（实测 6s）→ 改为 `getaddrinfo(AF_INET)` 单地址探测（3s）+ 结果缓存。修复后数据源接口稳定 0.02s。
