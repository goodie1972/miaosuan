## 网络数据源探测

- Dukascopy TCP/HTTP 均超时（沙箱内不可达）
- Yahoo Finance v8 API 返回 403（需 cookie/crumb，finance.yahoo.com 也 403）
- yfinance 持续 rate-limited（YFRateLimitError）
- Stooq 有 SHA-256 PoW JS 验证，Python 解出 PoW 后仍 Access denied
- Alpha Vantage demo key 不可用
- TradingView WebSocket 超时
- akshare 可用但只有上金所基准价（非 XAUUSD 现货）
- MT5 Python 包安装成功但机器无 MT5 终端（IPC initialize failed）
- 结论：网络数据源在当前环境不通，只能靠 MT4 本地导出
