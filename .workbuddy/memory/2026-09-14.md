# AgplComplianceMemory
- Ensure all future changes keep the project under AGPL‑3.0.
- Every new source file must include the AGPL header.
- The LICENSE file must remain at the repository root.
- Distributions (wheel, source tarball, Docker image) must ship the LICENSE and retain copyright notices.
- Web UI/Service must provide a link to the source repository and a download option.
- CI should run a check that every *.py contains the license header.
