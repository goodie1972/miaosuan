## 修复 gap-fill 平盘 bar 未过周期网格过滤的 bug

**问题根因**：`_parse_response` 中 gap 填充生成的平盘 bar（180-190行）没有走
周期网格过滤，导致 M5 14.4% / M15 37% / M30 54% 时间戳越界（产生非整 5/15/30
分钟的 bar）。真实 bar 有过滤（212-228行），gap-fill 没有。

**修复方案**：提取 `_passes_grid_filter(timestamp_ms, target_tf_seconds)` 统一函数，
应用于 gap-fill 平盘 bar 和真实 bar：
- M1 (60s)：no-op，所有 bar 天然在网格上（minute endpoint 原生粒度 60s）
- M5 (300s)：minute % 5 == 0 且 second == 0
- M15 (900s)：minute % 15 == 0 且 second == 0
- M30 (1800s)：minute % 30 == 0 且 second == 0
- H1 (3600s)：minute == 0 且 second == 0
- H4 (14400s)：hour % 4 == 0 且 minute == 0 且 second == 0

**验证**：真实 API 数据（2026-09-29 minute endpoint）测试：
- M1: 1439 bars parsed
- M5: 288 bars, off-grid = 0
- M15: 96 bars, off-grid = 0
- M30: 48 bars, off-grid = 0
全部通过。
