## R1. GATE（及其它双线性算子）在条件特征近零时的不连续跳变

**现象**
XAUUSD_H1 端到端对拍（8000 根，公式 `[33,62,3,87,72,119,73,103]`）中，因子序列在 **t=6231**
单点出现 O(1) 跳变（`max|Δ|=1.240`），其余 7999 点吻合（`p99.9|Δ|=4.29e-3`）。

**根因**
`GATE` 属「双线性（binate）」算子：其输出分支由**条件特征**的**符号**决定。
本公式条件特征为 `feat33 = TRIX_15`。在 t=6231 该条件恰好穿越 0：

```
trix_ours = +0.000e+00     trix_am = +9.379e-04
```

妙算的 numpy 实现在该点的 float32 归约得到 `0.0`（与参考基准的 `+9.4e-4` 仅差 1-ULP），
符号翻转导致选中不同分支 → 因子在**该点** O(1) 跳变、方向可能翻转。

**为什么不是移植 bug**
- 7999/8000 点逐点吻合；聚合统计逐位吻合（mean 0.258978 vs 0.258959、std 0.811758 vs
  0.811755、max 3.0、在市占比 0.920625）；
- 剔除「近零条件 bar」后 `max|Δ|=4.39e-3`；
- 复现完全确定（同输入同结果），两侧只是对同一浮点边界的**舍入方向**不同。

**为什么是真实风险（不只是移植噪声）**
实盘时若 `TRIX_15` 落在 0 附近（这类穿越在趋势反转处**经常发生**），因子会在相邻 bar 间
O(1) 跳变、甚至方向翻转，导致：
- 信号抖动 / 频繁进出场 → 换手与成本骤升；
- 按 `tanh` 映射后的仓位在 0 两侧跳变，中性带（`|pos|<0.05`）无法吸收这种幅度。

**建议处置（T04）**
1. 给双线性算子（`GATE` / `IF_GT` / `SIGN` 类）的条件**加死区（dead-band）**：
   条件绝对值 < `ε`（如 `ε = 1e-3 × cond_scale`）时沿用上一 bar 的分支或输出中性值；
2. 或在出口模板生成的目标策略里，对因子做**符号稳定性检查**（相邻 bar 符号翻转 → 平滑）；
3. 门禁侧增加「因子跳变率」软指标（`count(|Δfactor| > τ) / T`），超过阈值降级为
   `RESEARCH_ONLY`。

**影响范围**
- 所有含 `GATE` / `IF_GT` / 条件分支的公式；
- 所有**零点附近条件**（`TRIX` / `MOMENTUM` / `MA_DIFF` 等过零型特征）。

**对拍披露**
`tests/parity/test_e2e_xauusd.py::test_e2e_factor_pointwise` 已对该风险做**显式、有界、
可定位**的判定（`|Δ|>0.1` 的 bar ≤ 3 且必须落在近零条件 bar 上），并单独报告「剔除近零
条件 bar 后 `max|Δ|`」，**不通过放宽容差掩盖**。

## R2. 上游数据口径变更会被误判为「移植数值误差」

**现象**：复权 / 对齐 / 去重策略的任何改动都会**同时改变特征与因子**。
**处置**：口径变更必须**重建独立对拍基准**；不得沿用旧基准判定。详见
`docs/data_adaptation_checklist.md`。

---

## R3. `time < 1e7` 时间戳修复的边界

**现象**：`time.max() < 1e7` 才乘 1000；极端早期历史数据可能被误判。
**处置（T02 已部分落地）**：`data/loader.py` 保留自动判据但支持显式 `time_unit="s"/"ms"`
覆盖；建议 T04 在产物 `provenance` 记录实际使用的 `time_unit`。
